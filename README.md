# Matemática Discreta

Repositório com exercícios de Matemática Discreta implementados em Python. Os scripts abordam operações com conjuntos, lógica proposicional e relações, incluindo tabelas-verdade, matrizes e grafos.

## Como executar

É necessário ter Python 3 instalado. No terminal, acesse a pasta do repositório e execute o exercício desejado:

```bash
python ex-1.py
```

No Windows, também pode ser necessário usar `py`:

```powershell
py ex-1.py
```

Substitua `ex-1.py` por qualquer arquivo de `ex-1.py` a `ex-7.py`.
